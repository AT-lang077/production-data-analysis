# Production Data Analysis

Анализ производственных данных: загрузка и очистка датасета, расчёт показателей, визуализация и выводы.

Стек: **Python, Pandas, NumPy, Matplotlib, Jupyter**

## Данные
`data/production_data.csv` — 308 строк, синтетика: дата, линия (`Line-A/B/C`), смена, продукт, план/факт выпуска, брак, простои, энергия. Специально добавлены пропуски и дубликаты для демонстрации очистки.

## Запуск

```bash
pip install -r requirements.txt
jupyter notebook notebooks/analysis.ipynb
```

## Что внутри ноутбука
1. Загрузка и первичный осмотр (`shape`, `info`, пропуски, дубликаты)
2. Очистка: удаление дубликатов, заполнение пропусков медианами, тип даты
3. KPI: выполнение плана %, доля брака %, средний простой, энергоёмкость
4. Группировки по линиям и сменам
5. Графики в `outputs/`: динамика выпуска, брак по линиям, простои по сменам, энергия vs выпуск
6. Выводы

## Выводы (кратко)
- `Line-C` — самая проблемная: больше брака и ниже выполнение плана
- Ночная смена даёт в среднем +6 дефектов на партию
- Простои — ключевой резерв выпуска
